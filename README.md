## Descripción

Proyecto correspondiente a la **Práctica No. 1** de la asignatura **Informática II** de la Universidad de Antioquia.

Esta práctica tiene como propósito fortalecer el manejo del lenguaje C++, el entorno de desarrollo integrado **Qt Creator**, las herramientas de compilación con **CMake**, la depuración de programas y el desarrollo de habilidades algorítmicas mediante la solución de ejercicios y problemas.

La práctica está dividida en dos secciones principales:

* **Ejercicios:** 30 ejercicios enfocados en estructuras básicas de programación.
* **Problemas:** 17 problemas de mayor complejidad orientados al desarrollo de habilidades algorítmicas.

---

## Objetivos

* Afianzar el manejo del IDE Qt Creator.
* Mejorar las habilidades de depuración.
* Afianzar el manejo del asistente de depuración de Qt Creator.
* Afianzar el manejo del lenguaje C++.
* Conocer la estructura de un programa.
* Manipular diferentes tipos de datos.
* Afianzar el manejo de las estructuras de control.
* Desarrollar habilidades algorítmicas.

## Metodología de desarrollo

Cada ejercicio o problema se desarrollará siguiendo el siguiente proceso:

1. Leer y comprender el enunciado.
2. Identificar los datos de entrada.
3. Identificar el proceso necesario.
4. Determinar los datos de salida.
5. Realizar una prueba de escritorio.
6. Diseñar el algoritmo.
7. Identificar las estructuras y herramientas de C++ necesarias.
8. Implementar la solución paso a paso.
9. Compilar y ejecutar el programa.
10. Probar diferentes casos.
11. Utilizar el depurador cuando sea necesario.

El objetivo es comprender la lógica detrás de cada solución y no limitarse únicamente a escribir código funcional.
